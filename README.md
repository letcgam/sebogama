# Sebo Gama Link Tree

Landing page minimalista em React + Vite para o Sebo Gama.

## O que está incluso

- página única com links para WhatsApp, Instagram, Mercado Livre, Estante Virtual, Amazon e Shopee
- design inspirado em sebo retrô e acolhedor
- navegação rápida e responsiva
- build de produção pronta

## Como usar

1. Instale dependências

```bash
npm install
```

2. Rode em modo desenvolvimento

```bash
npm run dev
```

3. Acesse o app em `http://127.0.0.1:5173`

4. Gere o build de produção

```bash
npm run build
```

5. Visualize o build localmente

```bash
npm run preview
```

## Deploy recomendado

Você pode publicar no Vercel, Netlify ou GitHub Pages. Basta apontar para a pasta `dist` após a build.

## Estrutura de arquivos

- `src/App.jsx` — layout da landing page
- `src/styles.css` — estilo retrô e responsivo
- `src/main.jsx` — ponto de entrada React
- `index.html` — template HTML
- `vite.config.js` — configuração básica do Vite

## Observações

O site está pronto para receber seu logo definitivo. Se quiser, posso também adicionar ícones SVG mais refinados e um modo noturno com variações de cor.
